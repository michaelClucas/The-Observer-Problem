# Write-ups: the obligation and the rules

Aligned with the sibling repository's `explain/README.md`, deliberately, so
the two programmes produce comparable prose.

Any answer or partial answer this programme produces gets written up here
in language a late-highschooler could follow.

```
explain/
  NNN-<slug>.md     one per answer or partial answer
```

`NNN` matches the work package or run that produced the result, so a reader
can get from the prose back to the evidence.

## When one is written

At the point a work package reaches a conclusion, **including a negative
one**, and not at the end of the programme. A write-up deferred to the end
is one nobody can check against what was actually done, because by then the
reasoning has been reconstructed rather than recorded.

A write-up names the run, job or script its claims rest on, by directory.
No claim appears here that is not sourced there.

**A D3 or D4 verdict gets a write-up too**, and it is the harder one to
write honestly. "Here is a question about the universe nobody can currently
answer, and here is exactly what you would need in order to answer it" is a
real result and should read like one, not like an apology.

## The rules on the prose

**Explain the actual mechanism, in literal terms.** What the quantity is,
what it does, what changes when it changes. Literal description is almost
always possible and almost always shorter than the alternative.

**No invented analogies.** None of the fluent comparison-to-everyday-objects
register: no rubber sheets of our own devising, no ants on balloons, no bank
accounts, no traffic, nothing about backpacks. If an analogy is not already
standard in physics exposition, it does not go here.

**An analogy is permitted only where established physics exposition already
uses that specific one**, such as curved fabric for spacetime, and only
where the mechanism genuinely needs it. The test is whether removing the
analogy removes understanding or only removes decoration.

**No stakes inflation.** This repository's subject attracts grand framing,
and a write-up that opens on the nature of reality has already lost the
reader it was written for. Say what was measured.

**Name what is still open.** A write-up that ends on a clean conclusion when
the conclusion is provisional on WP-1, or on a Maple result, or on a choice
of collapse operator that no measurement selects, is misleading in exactly
the way this programme exists to avoid.
